# 포근별 마을 제품 기획서

## 1. 제품 한 줄 정의

부모의 구체적인 칭찬을 토큰과 별빛으로 바꾸어, 아이가 독창적인 동물 주민들과 마을을 성장시키는 가족용 힐링 게임.

## 2. 대상 사용자

- 귀여운 동물 캐릭터와 꾸미기를 좋아하는 어린이
- 결과보다 노력·배려·습관을 긍정적으로 강화하고 싶은 보호자
- 보호자와 아이가 함께 안전하게 사용할 수 있는 게임을 원하는 가족

## 2.1 기기 및 화면 전략

- **태블릿 우선:** iPad와 Android 태블릿의 가로 화면을 대표 경험으로 설계
- **휴대폰 대응:** 세로 화면에서 핵심 카드를 한 열로 자연스럽게 배치
- 900px 이상의 가로 화면에서는 마을과 정보 패널을 나란히 표시
- 태블릿 세로 화면에서는 콘텐츠 폭을 제한해 지나치게 늘어나지 않도록 구성
- 모든 주요 터치 영역은 어린이가 누르기 쉬운 크기와 간격을 유지
- 화면 회전 시 별도 재시작 없이 배치가 자동 전환

## 3. 핵심 게임 루프

```text
칭찬 기록 → 토큰·별빛 획득 → 꾸미기 아이템 수집
→ 건물 성장 → 새 주민과 이야기 해금 → 마을 확장
```

- **칭찬 토큰:** 가구, 의상, 장난감 획득에 사용
- **별빛:** 마을 전체 성장 경험치로 사용
- **칭찬 기록:** 보상보다 앞에 노출하며 언제든 앨범에서 다시 확인

## 4. 사용자 역할

### 보호자

- 가족 및 아이 프로필 관리
- 칭찬 메시지와 카테고리 작성
- 토큰 지급량과 일일 사용 한도 설정
- 거래 내역과 칭찬 기록 확인
- 뽑기 확률 및 안전 설정 확인

### 아이

- 받은 칭찬과 토큰 확인
- 가구·의상·장난감 수집
- 주민과 상호작용
- 건물과 마을 꾸미기
- 칭찬 앨범과 컬렉션 감상

## 5. 마을 성장 단계

| 단계 | 모습 | 주요 해금 |
|---|---|---|
| 작은 언덕 | 모모몽의 집 한 채 | 칭찬, 기본 꾸미기 |
| 포근한 이웃 | 주민 3명과 작은 길 | 주민 방문, 공동 가구 |
| 별빛 마을 | 광장과 상점 | 주민 이야기, 마을 행사 |
| 무지개 마을 | 테마 구역 확장 | 계절 행사, 특별 주민 |
| 포근별 왕국 | 모든 구역 연결 | 랜드마크, 장기 이야기 |

MVP는 첫 세 단계를 구현합니다.

## 6. 칭찬 카테고리와 시설

| 칭찬 | 연결 시설 |
|---|---|
| 노력·도전 | 모모몽의 모험학교 |
| 배려·친절 | 보보링의 선물공방 |
| 정리·차분함 | 포포의 구름정원 |
| 약속·꾸준함 | 두리콩의 별빛우체국 |
| 창의성 | 루루별의 밤하늘공방 |
| 감정 표현 | 토토밤의 포근도서관 |
| 협동 | 몽글이의 물방울놀이터 |

특정 칭찬 카테고리를 강요하지 않으며 모든 시설은 일반 별빛으로도 성장할 수 있습니다.

## 7. MVP 범위

- 보호자 이메일 로그인과 아이 PIN
- 가족 및 아이 프로필
- 칭찬 메시지, 카테고리, 토큰 지급
- 원장 기반 토큰 잔액
- 주민 4종과 등장 이야기 4편
- 마을 성장 3단계와 건물 6종
- 길·나무·울타리·가구 배치
- 가구·의상 중심의 뽑기와 인벤토리
- 주민 생활 애니메이션
- 칭찬 기록 앨범
- 일일 사용 한도
- 백업 및 계정 삭제

## 8. 아동 친화 설계

- 실제 화폐로 토큰을 구매하지 않음
- 광고, 공개 순위, 채팅, 친구 검색을 제공하지 않음
- 확률을 보호자와 아이 모두에게 공개
- 희귀도 대신 ‘언제나/가끔/특별한 날 만나는 아이템’ 표현 사용
- 뽑기 대신 별씨앗, 구름 우편함, 마법 알 등 부드러운 연출 사용
- 이미 받은 토큰을 벌점으로 회수하지 않음
- 접속하지 않아도 펫이 아프거나 마을이 파손되지 않음
- 최소한의 개인정보만 수집

## 9. 주요 데이터 구조

- `families`
- `users`
- `children`
- `praise_events`
- `token_transactions`
- `pets`
- `items`
- `inventories`
- `gacha_results`
- `rooms`

토큰은 잔액을 임의 수정하지 않고 거래 원장을 기준으로 계산·검증합니다.

## 10. 개발 일정안

| 단계 | 기간 | 결과물 |
|---|---:|---|
| 화면 및 시스템 설계 | 1주 | 사용자 흐름, 와이어프레임 |
| 기반 개발 | 1주 | 인증, 가족·아이 프로필 |
| 칭찬 토큰 | 1주 | 지급, 잔액, 거래 내역 |
| 아이템·인벤토리 | 1주 | 획득, 보관, 확률표 |
| 마을·주민 | 2주 | 성장, 건물, 생활 행동 |
| 보호 기능·테스트 | 1주 | PIN, 한도, 테스트 |
| 가족 테스트 | 1주 | 피드백 반영, MVP 배포 |

예상 MVP 기간은 약 8주입니다.
