# 포근별 마을 ✨

부모의 칭찬이 별빛이 되어, 아이와 귀여운 주민들이 함께 마을을 키우는 힐링 컬렉션 게임입니다.

## 핵심 경험

1. 부모가 아이의 노력·배려·약속·창의성을 구체적으로 칭찬합니다.
2. 아이는 칭찬 토큰과 별빛을 받습니다.
3. 아이는 마을 생활 속에서도 인사하기·감사 인사하기 같은 사회 매너와 물주기·편지 정리 같은 마을일 돕기를 실천하며 토큰을 모의로 벌 수 있습니다.
4. 토큰으로 가구·의상·장난감을 모읍니다.
5. 별빛으로 건물을 세우고 새로운 마을 구역을 엽니다.
6. 모모몽과 주민들이 이사 오며 새로운 이야기가 시작됩니다.

## 포근별 마을의 원칙

- 칭찬의 이유와 기록을 가장 중요하게 다룹니다.
- 토큰을 벌점처럼 회수하지 않습니다.
- 캐릭터는 이야기와 마을 성장으로 만납니다.
- 뽑기는 가구와 꾸미기 아이템 중심으로 운영합니다.
- 광고, 현금 토큰 구매, 공개 순위, 채팅은 제공하지 않습니다.
- 잠시 쉬어도 마을이나 캐릭터가 불이익을 받지 않습니다.
- 기존 유명 캐릭터를 모방하지 않는 독창적인 디자인을 사용합니다.

## 초기 주민

- **모모몽** — 용기와 도전을 상징하는 크림색 토끼
- **포포** — 차분함과 정리를 상징하는 솜구름 양
- **두리콩** — 약속과 꾸준함을 상징하는 아기 강아지
- **루루별** — 상상력과 창의성을 상징하는 별고양이

## MVP

- 부모·아이 프로필과 부모 PIN
- 칭찬 메시지 및 토큰 지급
- 토큰 거래 원장과 별빛 성장 시스템
- 주민 4종, 마을 성장 3단계, 건물 6종
- 가구·의상 중심의 뽑기와 인벤토리
- 주민 생활 애니메이션과 칭찬 앨범
- 일일 사용 한도, 데이터 백업 및 계정 삭제

## 권장 기술 구성

- React Native + Expo
- TypeScript
- Supabase + PostgreSQL
- Vitest + Playwright

## 실행하기

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm start
```

로직 테스트와 타입 검사는 다음 명령으로 실행합니다.

```bash
npm test
npm run typecheck
```

Expo 앱에서 다음 화면을 확인할 수 있습니다.

- 칭찬 토큰과 별빛 현황
- 오늘 받은 칭찬 카드
- 성장 중인 포근별 마을
- 모모몽·포포·두리콩·루루별 상호작용
- 건물 터치와 주민 상태 메시지
- 다음 구역까지의 성장 진행률
- 태블릿 가로 화면의 마을·정보 패널 분할 배치
- 휴대폰 세로 화면의 한 열 스크롤 배치
- 친구별 상태를 확인하는 친구 화면
- 토큰으로 아이템을 구매하는 꾸미기 화면
- 칭찬과 토큰 거래를 확인하는 앨범 화면
- 중복 지급·잔액 부족을 방지하는 토큰 거래 원장
- 별빛 성장에 따라 새 주민·건물이 순서대로 열리는 마을 성장 단계
- 구매한 가구를 마을 뜰에 직접 배치하는 꾸미기 자리
- 아침·낮·저녁·밤에 따라 다르게 지내는 주민 일과
- 날짜에 맞춰 뜨는 계절 축제 배너
- 이웃과 인사하기·감사 인사하기 등 마을 생활 매너를 실천하고 토큰을 받는 활동
- 구름정원 물주기 돕기·편지 정리 돕기 등 마을일을 돕고 토큰을 받는 활동
